Simon Game

The Simon Game is an interactive web-based memory game inspired by the classic electronic Simon game. The objective is to remember and repeat a sequence of colors displayed by the system. With each successful level, a new color is added to the sequence, increasing the difficulty and challenging the player's memory and concentration skills.

This project was developed using HTML, CSS, JavaScript, and jQuery to create a responsive and engaging user experience. It demonstrates key frontend development concepts such as DOM manipulation, event handling, animations, sound integration, and game logic implementation.

Features
* Dynamic random sequence generation
* Progressive difficulty with multiple levels
* Interactive sound and visual effects
* Real-time user input validation
* Game-over detection and restart functionality
* Responsive design for different screen sizes

Technologies Used
* HTML5
* CSS3
* JavaScript (ES6)
* jQuery

How I Built This Project

* Implemented game logic using JavaScript.
* Used jQuery for event handling and DOM manipulation.
* Created random color sequences for each level.
* Added sound effects and animations to improve user experience.
* Implemented level tracking and game-over functionality.
